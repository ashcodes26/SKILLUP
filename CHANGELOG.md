# Changelog

All notable changes to the **SKILLUP** platform are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.0.0] - 2026-11-09

### Added
- **Interactive 3D Particle Brain Component** (`ParticleBrain.tsx`):
  - 5,200 particle cortical surface with mathematical sulci delineation.
  - Three structural color zones: Frontal cortex (Electric Iris / Violet), Parieto-Temporal-Occipital mantle (Luminous Mint / Cyan), and Cerebellar/Brainstem axis (Radiant Saffron / Gold).
  - High-performance canvas physics with mouse hover particle deflection, pointer drag rotation (yaw & pitch), and spherical ripple waves.
  - Full keyboard navigation and reduced-motion accessibility support.
  - Embedded compact mode integrated into the Career Plan executive hero header.
- **Cinematic Warp-Speed Login Transition** (`LoginTransition.tsx`):
  - Luminous particle burst with radial shockwave and speed-scaled streak lines.
  - Dissolve climax into authenticated student/faculty dashboard.
  - Accessible floating "Skip ›" button with `Escape` / `Tab` shortcut.
- **Unified Clean Authentication View** (`LoginScreen.tsx`):
  - Interactive neural mesh embedded directly on the landing page.
  - One-click instant Sandbox triggers for Demo Student and Placement Faculty.
  - Dedicated student registration flow.
- **Documentation & Architecture Standards**:
  - Comprehensive `README.md` with module guides, installation steps, and compliance disclosures.
  - Standardized project metadata and changelog tracking.

### Changed
- **Branding & Identity**:
  - Rebranded project as **SKILLUP**.
  - Reverted and polished Skillup header brand with canonical terminal insignia.
  - Unified color system around Obsidian Dark Theme palette (`#070709` / `#101014` / `#8052ff`).
- **Asset Migration**:
  - Migrated avatar and reference assets from legacy studio paths to canonical `/assets/media/` structure.
  - Updated profile file ingestion parser descriptions and service references.

### Removed
- Removed legacy Google AI Studio export footprints, metadata files, and `.aistudio` artifact storage.
- Removed outdated placeholder components and extraneous debug boundaries.

## [0.9.0] - 2026-10-28

### Added
- Deterministic career readiness calculation engine with strictly audited benchmark criteria.
- Student Career Plan module with target role switcher, competency gap analysis, and proof-of-work drawer.
- Placement Director Faculty Console featuring cohort overview, skill analytics, and company drive manager.
- Reactive Interviewer 3D Avatar with real-time speech synthesis and audio response analysis.
- Multi-format student file ingestion supporting `.csv`, `.xlsx`, `.tsv`, `.json`, and resume `.pdf`.
